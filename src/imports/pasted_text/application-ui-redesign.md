ORANGE GLOW SYSTEM
==================================================

Use subtle orange atmospheric lighting.

Preferred glow:

rgba(255,106,0,0.18)

Secondary glow:

rgba(255,106,0,0.08)

Use glow selectively.

Glow should appear around:

- primary CTA buttons
- active sidebar item
- selected network nodes
- high priority alerts
- important statistics
- focused input fields
- important graph relationships
- hover states

Do not add orange glow to every component.
